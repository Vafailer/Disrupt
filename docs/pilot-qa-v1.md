# Mock-приёмка Telegram и админки

8 октября 2026 года. Ветка `feature/andrey-pilot-qa-v1` от `c8261b80bedbdbe3f6505b5af8c1616fdae5f69d`. Задание `docs/andrey-parallel-work-v1.md` прочитано из более позднего `origin/feature/server-deploy-v1`, поскольку в указанной базе файла ещё нет.

## Исправления

- Бот объясняет, что запрос привязки нужно подтвердить в вебе. До подтверждения записи из бота не сохраняются.
- `/save` явно обозначен как сохранение текста без ИИ. Подтверждение голосовой записи сообщает о сохранённом оригинале, а не обещает готовую расшифровку. При выключенном распознавании предложен текстовый ввод.
- При переходе между страницами usage фокус переносится на таблицу. До исправления скрытие dashboard сбрасывало фокус на документ, мешая работе с клавиатурой.
- Изменение фильтра во время загрузки сбрасывает `aria-busy`. Устаревший ответ по-прежнему не отображается.
- Колонки админки могут сжиматься, кнопки пагинации переноситься, длинная подпись периода переносится внутри блока. До исправления на ширине 360 px документ растягивался до 361 px.

Offset, журнал доставки, обработка unknown, блокировка второго бота и контракты не менялись.

Добавлена проверка сообщений help, ручного сохранения и ожидающей подтверждения привязки через HTTP MockTransport. Проверка голоса дополнена утверждением о сохранении оригинала без обещания готовой расшифровки.

## Повторение браузерной проверки

В отдельном checkout с установленными зависимостями запустить `PYTHONPATH=. python tests/manual_admin_server.py` и открыть `http://127.0.0.1:8765/qa`.

Стенд создаёт временную БД и синтетического администратора, не читает deployment-секреты. `real` использует настоящий API пустой БД. `fixture` подставляет эталонный JSON и 50 длинных строк только после успешной серверной авторизации. `loading` задерживает ответ, `error` возвращает 503. Вторая вкладка с `revoke` или `expire` позволяет отозвать роль или сессию, затем обновить статистику в первой вкладке. `/qa/narrow` открывает локальный экран шириной 360 px.

Стенд намеренно выдаёт тестовую сессию без входа. Только для локального запуска на 127.0.0.1, никогда не развёртывать и не проксировать наружу. Возможность встраивания в iframe включена исключительно в стенде для `/admin?qa_embed=1`. Заголовки защиты приложения не менялись. После Ctrl+C временные данные удаляются.

## Нерешённые вопросы ядра

Новых воспроизводимых дефектов ядра в этой проверке не найдено. Бот не получает признак доступности STT, поэтому объяснение остаётся условным. Автоматическое сообщение о готовности расшифровки не добавлялось. Подтверждение живого протокола STT, HTTPS, реальная доставка и включение worker остаются отдельной приёмкой команды. Cloud.ru и настоящий Telegram не вызывались, VPS не использовались.

## Первая совместная приёмка

1. Марк поднимает отдельное mock-окружение с двумя тестовыми аккаунтами. Андрей запускает тесты адаптера с MockTransport. До подтверждения привязки запись отклоняется; после подтверждения привязанный аккаунт получает запись, второй аккаунт её не видит.
2. Андрей проверяет `/save` и голос на синтетическом аудио. Марк сверяет исходник, отсутствие AI job в ручном режиме и доступность оригинала при ошибке STT. Повтор update не создаёт второй записи.
3. Андрей проверяет напоминание, кнопку выполнения и перезапуск адаптера через подменённый Telegram. Марк сверяет состояние задачи и Outbox. Unknown не отправляется повторно.
4. Марк запускает локальный браузерный стенд. Андрей проверяет фильтры, следующую и предыдущую страницу с клавиатуры, длинные строки на 360 px и CSV. Марк отзывает роль, затем сессию во второй вкладке. Андрей обновляет первую и проверяет скрытие данных и запрет экспорта. Локально эти сценарии пройдены. При серверной приёмке повторить на согласованной сборке.
