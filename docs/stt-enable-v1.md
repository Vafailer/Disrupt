# Включение распознавания речи

## Почему STT выключен

Compose не передавал в worker настройки `NOTES_STT_*`, поэтому включить распознавание было нельзя. Теперь передаёт, по умолчанию всё выключено. Кроме того, протокол шлюза и точное имя STT модели не подтверждены. Адаптер отправляет запрос в стиле OpenAI на `/audio/transcriptions`, но живой сервис не проверялся.

## Проверка на ядре

Команды ниже используют `beresta-core`, ту же обёртку над Compose, что и при установке. Если запускаете по-другому, берите те же Compose-файлы и `--env-file`.

Нужно `NOTES_ALLOW_LIVE_REQUESTS=true` в `.env.production` и ключ в секрете worker. Проверка идёт мимо лимитов приложения, ничего не пишет в базу и не меняет счётчики. Каждый запуск стоит денег. Хватит двух или трёх запусков за всё время.

1. Найти модель.

```
beresta-core --profile owner-live run --rm --no-deps worker python -m app.stt_probe --list
```

Скрипт делает один запрос `GET /models` и отмечает модели, в имени которых есть whisper, stt, speech, audio или asr. Отметка только подсказка. Выбрать нужно вручную.

2. Короткий файл. Запишите голосовое в Telegram секунд на 15 или возьмите свой файл `.ogg`, `.wav` или `.webm`. Положите в каталог `probe` на сервере и сделайте файл читаемым (`chmod 644`). Каталог подключается к одноразовому контейнеру.

```
beresta-core --profile owner-live run --rm --no-deps -v "$PWD/probe:/probe:ro" worker \
  python -m app.stt_probe --file /probe/short.ogg --model ID
```

Скрипт напечатает код ответа, время, длину текста и первые 200 символов. Убедитесь, что текст соответствует записи.

3. Длинный файл на 2 или 3 минуты. Так же, с другим именем файла. Сравните конец расшифровки с концом записи. В каталоге Cloud.ru у whisper-large-v3 указан контекст 448, он может обрезать длинные записи. Если конец потерян, не включайте STT и сообщите об этом команде.

Коды ошибок. `stt_model_not_found` значит неверное имя модели или нет такой конечной точки. `stt_auth` значит ключ не подходит. `stt_invalid_response` значит формат ответа не совпал с ожидаемым, протокол не подтверждён.

## Включение

Если оба файла расшифровались полностью, добавить в `.env.production`

```
NOTES_STT_ENABLED=true
NOTES_STT_PROTOCOL_CONFIRMED=true
NOTES_STT_MODEL=ID
```

Пересоздавать только worker и только когда очередь пуста. Оплачиваемый запрос прерывать нельзя. Простаивающий worker штатно останавливается через SIGINT, подробности в [release-handoff-v1.md](release-handoff-v1.md). Профиль остаётся `owner-live`, `restart` остаётся `"no"`.

```
beresta-core --profile owner-live up -d --no-deps --force-recreate worker
```

Одна голосовая заметка занимает два слота лимита, один для STT и один для LLM. Учтите это при общем и пользовательском лимитах.

## Откат

Задать `NOTES_STT_ENABLED=false` в `.env.production` и пересоздать worker той же командой. Новые голосовые задания снова получат `stt_not_configured`, оригиналы сохранятся.
