# Почта для регистрации

SMTP.BZ подтверждён владельцем. Из-за блокировки SMTP-портов у VDSina планируется HTTPS API. TLS api.smtp.bz:443 проверен с российского VPS, авторизация и доставка ещё не проверялись. Текущий сайт использует логин и пароль, почтовой регистрации пока нет.

Ветка `feature/email-auth-v1` отдельная, база выпуска focus UI. Перед изменением модели User и миграций согласовать пересечение с работой Андрея над Telegram Login. Сохранять существующие аккаунты, user_id и привязки.

Владелец запускает `save-smtp-bz-key.cmd` и вводит API-ключ скрыто. Скрипт использует существующий ssh-agent и не пересылает его. Ключ передаётся через SSH stdin только на ядро, сохраняется в `secrets/smtp_bz_api_key.txt` с правами 0400 для UID 1000. Существующий файл не перезаписывается. Содержимое SSH-ключа не читается. В Git и Хельсинки API-ключ не попадает. Скрипт не проверяет ключ у провайдера и не отправляет письма.

После сохранения ключа нужно определить адрес отправителя, реализовать почтовую очередь, подтверждение email и восстановление пароля. Проверки кода используют mock и отдельную базу. Фактическую доставку подтверждать отдельной проверкой владельца.
