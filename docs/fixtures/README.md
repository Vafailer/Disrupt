# Пример данных для админки

admin-summary.json содержит вымышленные данные для разработки экрана
и проверки расчётов. Работающего admin API пока нет.

В примере выбран период 5-6 октября 2026 года включительно, Europe/Moscow,
канал all и источник all. Расчёт сделан на 7 октября, 12:00 МСК.
Alpha впервые вошёл 5 октября в 09:00, Beta вошёл 6 октября в 09:00.
Тестовый пользователь Test исключён полностью. Источник у всех unknown.

Alpha сохраняет capture A в Telegram 5 октября в 09:02, открывает его в вебе
в 09:04 и подтверждает структуру в 09:05. Повтор события сохранения использует
тот же event_id и operation_id, поэтому не считается дополнительным действием.
6 октября в 09:00 Alpha возвращается к записи через поиск, уже после активации.
В 09:02 он делает ещё одну AI-запись в вебе. Её обработка завершается ошибкой.
В первый день действия Alpha в двух каналах дают DAU=1.

Beta сохраняет ручную запись 6 октября в 09:02, открывает её в 09:04
и подтверждает ручное напоминание в 09:05.
У него завершена manual activation, но проверки AI-структуры нет.
В полный AI-сценарий и шаг structure_checked входит только Alpha.
Ручная активация показана отдельно.
Return означает открытие поиска или напоминания после активации.
У Beta такого события ещё нет. Фоновая обработка и отправка не входят в DAU.

DAU за первый день равен 1, за второй равен 2.
Уникальных пользователей за период 2, сумма дневных DAU равна 3.
За период new_users=2 и returning_users=0, оба впервые вошли в эти даты.
Во второй день Alpha считается вернувшимся, Beta новым.
Аналитических сессий три. Alpha имеет по одной в каждый день,
Beta одну во второй день. Каналы объединяются, фон сессию не продлевает.

У обоих пользователей прошло окно 24 часа.
Поэтому ai_activation=1/2, manual_activation=1/2 и pending=0.
D1 Alpha завершён и активен, получается 1/1.
D1 Beta ещё не завершён, 7 октября пока текущий день.
Для обеих когорт D7 ещё не наступил, поэтому 0/0, value=null и pending_d7=2.

Первая вымышленная модельная операция Alpha стоит 0.25 RUB, её usage известен.
У второй нет измеренного usage и тарифа. Её стоимость неизвестна.
За первый день cost/DAU=0.25. За второй день и весь период полная стоимость
и cost/DAU равны null. Известный подытог 0.25 хранится отдельно,
unknown_usage_calls=1. Тариф fixture-only-v1 придуман для примера
и не относится к Cloud.ru. STT-вызовов здесь нет.

Перед приёмкой admin API нужно создать эти данные в тесте и сверить
расчёт с JSON и CSV. В этой ветке проверены форма ответа и арифметика долей.
Сам расчёт статистики ещё предстоит написать.

telegram-save-ai.json и telegram-save-manual.json содержат примеры ответов
внутреннего текстового API с nullable job_id и стабильной ссылкой.
Все UUID и домен вымышленные. Завершение Job не меняет сохранённый AI-ответ.
Повтор update возвращает тот же ответ. Текущее состояние читается
через Capture/Job.
