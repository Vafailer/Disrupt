# Telegram UX v1

Ветка `feature/claude-telegram-ux-v1`. Привязка Telegram в один шаг, приветствие и меню кнопками.

## Что изменилось

Веб (`app/static/telegram-link.js`, подключён после `app.js`)
- Кнопка «Подключить Telegram» создаёт код и показывает «Открыть бота». Текст `/start код` остался запасным путём.
- Имя бота лежит в одной константе `BOT_USERNAME` в начале файла.
- Пока код активен (10 минут), страница раз в 3 секунды читает `GET /api/v1/telegram/links`. Когда появляется запрос с нашим `link_request_id`, он подтверждается сам. Опрос стоит на паузе в скрытой вкладке, останавливается при успехе, истечении кода и выходе.
- Ссылка `/#telegram-confirm` из бота подтверждает единственный ожидающий запрос пользователя. Если вход ещё не выполнен, это произойдёт сразу после входа. `/#telegram` просто открывает окно Telegram. Хеш очищается.
- Привязанный аккаунт показан как «Telegram подключён». Блок про Telegram удалён из `app.js`, `onboarding.js` читает новый текст.

Ядро
- `GET /internal/v1/telegram/link-requests/{id}?telegram_user_id=N` под сервисным токеном. Ответ `{"status": "issued|pending|confirmed|expired", "username": ...}`. Имя только для `confirmed` и только при совпадении `telegram_user_id`. Иначе 404. Просроченный по времени запрос считается `expired`.
- Маршрут скрыт из OpenAPI (`include_in_schema=False`), `docs/integration-v1.*` не менялись.

Бот
- Постоянное меню: «📝 Записать», «✍️ Без ИИ», «🔗 Подключить аккаунт», «🌐 Открыть beresta», «❓ Помощь», «🏠 Меню». Тексты кнопок не сохраняются как записи.
- `/menu`, `/help`, `/start` без кода, `/save текст` работают. Список команд ставит `setMyCommands` при старте.
- После `/start код` бот отвечает кнопкой «Открыть beresta» на `/#telegram-confirm` и ждёт подтверждения до 10 минут, затем пишет приветствие. Наблюдатель один на чат.
- Метка «Без ИИ» и наблюдатели хранятся в памяти. После перезапуска приветствие не придёт, привязка работает.

## Как проверить на сервере

1. Обновить API и бота, перезапустить оба. В журнале бота не должно быть `bot_commands_not_set`.
2. В Telegram отправить боту `/menu`. Кнопки должны появиться внизу. Нажать каждую: «Записать» и «Помощь» отвечают текстом, «Без ИИ» подтверждает режим, «Подключить аккаунт» и «Открыть beresta» дают кнопку-ссылку.
3. Нажать «Без ИИ», отправить текст. В beresta запись без разбора ИИ. Следующий текст идёт уже в ИИ. Подпись кнопки не должна появиться среди заметок.
4. В вебе войти, открыть Telegram, нажать «Подключить Telegram», затем «Открыть бота» и «Запустить». Окно должно само показать «Telegram подключён», а бот написать «Вы присоединили учётную запись. Добро пожаловать, имя!» с меню.
5. Повторить с выходом из веба: открыть бота по ссылке, нажать «Открыть beresta» в ответе бота, войти. Подключение должно завершиться после входа, в адресе не остаётся `#telegram-confirm`.
6. Подождать 10 минут без бота. Окно должно написать, что код истёк.
7. Перезапустить бота сразу после `/start код` и подтвердить вручную. Привязка работает, приветствия нет.

## Что не проверено

Живые Telegram и браузер не использовались. Python-тесты и jsdom в среде разработки не запускались, их запускает CI.
