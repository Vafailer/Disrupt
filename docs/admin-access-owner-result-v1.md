# Доступ Марка к админке

На обоих VPS работает сборка `4acd3f79e7b241aec0d2e09423af124c0281a1d2`.
Почта и регистрация по email выключены, дальнейшую настройку почты ведёт Андрей.
Страница конфиденциальности не менялась по просьбе владельца.

Создан отдельный администратор `mark`. Пароль сгенерирован из 24 случайных
байт, 32 символа. Пароль и секрет TOTP сохранены только в закрытом файле
`Beresta-owner-secrets/mark-authenticator.txt` на ПК Марка. Копия сверена.
Файл доступен Марку и системе Windows, остальным права не выданы.
Открытая временная серверная копия удалена. В БД пароль хранится как scrypt,
секрет аутентификатора зашифрован ключом данных.

Автоматически подтверждён TOTP и проверен настоящий приватный вход.
Статистика, CSV, ZIP метрик, журнал действий и выход отвечают корректно.
С ПК проверен SSH-туннель, форма даёт 200, API без сессии даёт 401.
Пароль, секрет, коды, cookies и содержимое выгрузок в результаты не выводились.
Импорт в Google Authenticator на телефоне выполняет владелец, агент его не проверял.

Порядок для Марка.

1. В Google Authenticator добавить аккаунт вручную. Имя `beresta mark`,
   ключ из строки `Manual setup key` сохранённого файла. Тип по времени.
2. Запустить `scripts/open-admin.cmd`. Откроется `http://127.0.0.1:18000/admin`.
   Окно туннеля оставить открытым.
3. Ввести логин `mark`, пароль из строки `Password` и свежий код с телефона.
   Один код работает один раз. Если только что использовали его, дождаться следующего.
4. Сохранить файл ещё в менеджере паролей. Ключ данных и ключ age хранить отдельно
   от архивов базы и аудио.

Для Андрея создать отдельный аккаунт и секрет аутентификатора. Для собственного
туннеля нужен его публичный SSH-ключ с ограничением на проброс порта.
Приватный SSH-ключ Марка и ключ шифрования данных для входа Андрею не нужны.

Изменения скрипта генерации проверены семью тестами без сети и рабочих данных.
Генератор отказывается перезаписывать файл и не выводит пароль или секрет.
Проверочный TOTP совпадает с действующей реализацией на тестовых векторах RFC.
