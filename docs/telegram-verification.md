# Проверка Telegram адаптера

5 октября 2026. macOS, Python 3.12, зависимости из существующего requirements.txt. Проверки выполнялись без ключей команды и без внешних запросов Telegram/STT/LLM.

- До изменений: 52 passed, 1 skipped.
- После добавления адаптера: 96 passed, 1 skipped, из них 44 новых теста адаптера.
- Пропущен PostgreSQL-тест: отдельная тестовая БД не настроена. SQLite-тесты не заменяют приемку PostgreSQL.
- `python -m telegram_adapter --demo`: успешное сохранение через фиктивный HTTP API, подтверждение и защита от повторного update; сеть не использовалась.
- Проверены: приватный чат и actor, сохранность текста, /save, привязка, отсутствие ложного «сохранено», неправильные URL/ответы, 429, сбой после commit, частично обработанная пачка, checkpoint после перезапуска, один poller, безопасные логи, голосовой multipart и лимит фактического размера, закрытый ввод секретов.
- Предупреждение существующего стека Starlette о будущем переходе TestClient с httpx на httpx2 не исправлялось изменением общих зависимостей Марка.

Не проверены: живой Telegram, STT/LLM, связка с реальными новыми API ядра, PostgreSQL новых сущностей, Docker, сервер и доставка напоминаний. Это первый этап адаптера, не приемка всего MVP.
