# Режим фокуса на VPS

База `3b08fc69d77514613a280ef37be781c9b8ac555b`, PR #31. Отдельная ветка выпуска `feature/focus-ui-vps-release-v1`. Main и ветки коллеги не меняются.

Сохранён установленный перенос расшифровки в новую заметку. Он адаптирован к значкам вместо capture-tabs и кнопке «Сохранить». Оригинальное аудио остаётся, сохранение текста не запускает STT или ИИ без следующего действия пользователя.

В автосохранении обнаружен сбой после flush без правок. Promise завершался синхронно, ссылка running оставалась и блокировала следующие сохранения. Сброс вынесен в finally самого Promise. Новый тест сначала воспроизвёл отсутствие PATCH, после исправления прошёл. Проверки одного запроса, последнего текста и конфликта версий сохранены.

Локально прошли focus, audio, web_structure, brain, очередь, onboarding, напоминания, админка и Ruff. Настоящий ключ в тестах не используется. Из Python относительно работающей сборки меняются только инструкции модели о стиле ответа. Доступность и качество нового промпта реальным запросом не проверяются.
