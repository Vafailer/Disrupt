Из Python относительно работающей сборки меняются только инструкции модели о стиле ответа. Доступность и качество нового промпта реальным запросом не проверяются.

Схема `f3a82c91d507` уже установлена и проверена в предыдущем выпуске. Новых миграций, зависимостей и изменений Compose нет. Перед обновлением нет активных заданий ни в jobs, ни в assistant_requests. Общий счётчик 20, лимиты 1000/100.
