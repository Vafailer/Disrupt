Первое обращение ответило за 23,3 секунды, но результат не прошёл разбор формата. В подменённых тестах проверен разбор JSON в оболочке и текстовых блоках с прежней строгой схемой и проверкой цитат. Следующее настоящее обращение завершилось успешно за 6,8 секунды, заметка сохранена с провайдером `cloudru`. Качество текста должен оценить владелец. Исходники неуспешных заданий сохранены, автоматического повтора этих заданий нет.

При исчерпании общего предела worker сохраняет очередь и ждёт изменения лимита. Веб сообщает об исчерпании лимита и оставляет ручное сохранение. Предел учитывает все попытки для этой базы, включая ошибки; это не дневной бюджет и не баланс Cloud.ru.

Ссылка «Наш Telegram» установлена в правой части шапки. Цвета, рамка, скругление, иконка и стрелка соответствуют оформлению коллеги. Регистрация повторно открыта владельцем на пять часов до 20:50:55 Москвы 9 октября; постоянный таймер обновлён.

Обычный Dockerfile для CI не менялся. Исходники обеих VPS синхронизированы до `f23fdbe`, API и worker собраны с этой версией. HTTPS/VPN probe прошёл, бот остаётся единственным работающим экземпляром.

На подменённом транспорте прошли 37 тестов провайдера, дополнительно 14 целевых тестов runtime и защиты бюджета.
