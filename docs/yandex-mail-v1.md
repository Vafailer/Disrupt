# Яндекс 360 для Beresta

Выбран один ящик на `berestaapp.ru`. На 10 октября минимальный тариф стоит
319 рублей в месяц за сотрудника. Подключение и оплату выполняет владелец
в https://360.yandex.ru/business/tariff/.

1. Создать организацию, выбрать минимальный тариф для одного сотрудника.
2. Добавить `berestaapp.ru`. Подтвердить домен TXT-записью из кабинета Яндекса.
3. В Timeweb настроить почтовые записи вручную. DNS-серверы и A-записи сайта оставить.
4. Создать ящик, например `no-reply@berestaapp.ru`, и один раз войти в его веб-почту.
5. В настройках разрешить почтовые программы и пароли приложений. В Яндекс ID
   создать пароль приложения для почты. Обычный пароль аккаунта не использовать.
6. Запустить `scripts/save-yandex-smtp-password.cmd` и вставить пароль в скрытый ввод.
   Сообщить Codex только адрес ящика и что пароль сохранён.

Почтовые DNS-записи Яндекса.

| Тип | Поле «Хост» в Timeweb | Значение |
| --- | --- | --- |
| MX, приоритет 10 | пустое | `mx.yandex.net.` |
| TXT, SPF | пустое | `v=spf1 redirect=_spf.yandex.net` |
| TXT, DKIM | `mail._domainkey` | Новый ключ из кабинета Яндекса |

SPF нужно заменить в существующей записи, а не добавлять второй SPF.
Ключ SMTP.BZ не подходит для DKIM Яндекса. TXT подтверждения домена создаётся
дополнительно по значениям Яндекса. TTL 600 подходит для настройки.

С российского VPS исходящие SMTP-порты сейчас недоступны. Владелец отправляет
поддержке VPS это сообщение.

> Здравствуйте! Для приложения Beresta на VPS 178.217.98.101 нужны исходящие
> TCP-соединения на порт 587 к smtp.yandex.ru с STARTTLS. Будем отправлять
> письма подтверждения адреса и восстановления пароля. Рекламных рассылок
> не будет. Просьба разрешить эти соединения.

После открытия порта Codex подключает пароль только к API, задаёт SMTP-пользователя
и адрес отправителя равными созданному ящику и проверяет доставку с владельцем.
На сервер бота пароль не передаётся. Сейчас отправка выключена.

PR #33 содержит подтверждение привязки email по ссылке и восстановление пароля.
Регистрация с почтой и шестизначным кодом требует отдельной реализации.

Инструкция Яндекса https://yandex.ru/support/yandex-360/business/admin/ru/mail/start.
