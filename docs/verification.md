# Проверка текстового прототипа

29 сентября 2026 года, Windows, Python 3.12.14, SQLite.

- `pytest -q`: 37 тестов прошли; 1 PostgreSQL-тест пропущен, поскольку локальная PostgreSQL не настроена. Есть предупреждение Starlette об устаревании httpx в TestClient; текущие проверки проходят.
- `ruff check app tests migrations`: без ошибок.
- `alembic upgrade head` и `alembic check`: миграция применена, расхождений схемы не найдено.
- Через браузер проверены регистрация тестового аккаунта, встроенный пример, автоматическая обработка, открытие заметки, редактирование заголовка, принятие вывода и повторное открытие после обновления страницы. Оригинал и версия 3 сохранились.
- Тесты отдельно проверяют сохранность после создания нового экземпляра приложения, запрет доступа к чужим данным, дубль запроса, конфликт версий, ошибки HTTP и ответа модели, истечение задания, конкурентных worker и лимиты запросов.
- Cloud.ru: только `httpx.MockTransport`, вымышленный ключ, никакой проверки реального доступа, списка моделей или баланса. Настоящий API-токен не использован.
- Docker, PostgreSQL и GitHub Actions подготовлены, но их успешное выполнение пока не подтверждено. Публикация в GitHub отложена пользователем до настройки авторизации.
- Голос, Telegram и PWA ещё не реализованы; качество настоящего ИИ не проверено.
