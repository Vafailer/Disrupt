# Что проверено

Последняя подробная проверка текстового сценария проводилась локально на Windows с Python 3.12.14 и SQLite. Это запись о выполненных проверках, а не обещание, что серверная конфигурация уже запущена.

- `pytest -q` завершился с 52 пройденными тестами. Один тест PostgreSQL был пропущен, потому что локальная база не настроена. Starlette вывел предупреждение об устаревании использования httpx в TestClient.
- `ruff check app tests migrations` прошёл без ошибок. `alembic upgrade head` применил миграции, а `alembic check` не нашёл расхождений схемы.
- В браузере были проверены регистрация, пример записи, обработка, открытие заметки, изменение заголовка и принятие вывода. После обновления страницы исходный текст и третья версия заметки сохранились.
- Автоматические тесты охватывают доступ к чужим данным, повторную отправку, конфликт версий, ошибки модели, истечение задания, работу нескольких worker и лимиты запросов.
- Автоматические тесты использовали вымышленный ключ и `httpx.MockTransport`. Агент не применял настоящий токен. Владелец ключа подтвердил работу модели в приложении. Баланс и качество ответов отдельно не проверялись.
- Разделение API и worker проверялось тестами конфигурации. API работает без модельного секрета, worker может читать его из отдельного файла.

Docker не был установлен на машине разработки, поэтому локальный запуск PostgreSQL и `compose.production.yaml` не проверялся. Голос, Telegram и установка PWA в этой версии отсутствуют. Перед пилотом команде нужно отдельно проверить серверное развёртывание и качество настоящей модели своим ключом.
