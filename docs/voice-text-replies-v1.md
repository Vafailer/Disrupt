# Голос и текстовый результат

На обоих VPS установлен `6da32e38a3a6c8bdb117657c59a7b52a6e51a5f6`, PR #21. Распознавание новых записей включено по явному разрешению владельца. Main и ветки коллеги не менялись.

Речь распознаёт `whisper-large-v3`, заметку собирает прежний `deepseek-v4-flash`. Обе модели используют `https://shared1.multitool.works:4000/v1`. Каталог шлюза подтвердил короткий ID Whisper, публичная OpenAPI-схема содержит `/v1/audio/transcriptions`.

Оригинал сохраняется неизменным. Копия переводится в WAV, 16 кГц, один канал, с ограничениями декодера. Запрос содержит file, model и language=ru, без response_format. Расшифровка сохраняется до LLM, lease продлевается для второго этапа. Истёкший lease не возобновляется.

Готовый результат входящей записи Telegram отправляется текстом через существующие claim/authorize/result и журнал адаптера. Веб показывает ту же заметку. Outbox привязан к исходным job, bot и chat; уникальный job_id исключает повтор доставки после повторного update. Перед отправкой проверяются владелец и действующая связь. Неопределённая отправка не повторяется. Веб-записи автоматически в Telegram не рассылаются. Длина текста ограничена по UTF-16, полный результат доступен по ссылке.

Миграция `e61f893ac204` после `d84f210ac937` сохраняет прежние напоминания. Downgrade при наличии состояния новых доставок запрещён, чтобы не потерять его.

## Проверки

- Владелец отдельно разрешил каталог и три последовательные STT-пробы. WebM с прежними параметрами вернул 400. WAV без языка тоже вернул 400, диагностика указала language. WAV с language=ru распознан успешно, 154 символа, HTTP-этап 449 мс. Качество текста владелец ещё не оценивал.
- Пробы учтены в бюджете и ProviderUsage. Ключ, расшифровка и тело ошибки не выводились. Повтор одноразового probe запрещён сохранённым receipt.
- Оба CI `6da32e3` зелёные. Проверены PostgreSQL, миграции, контракт, Ruff, DOM, образы и восстановление. Локальный Linux-прогон дал 535 passed, после исправления одной синтетической фикстуры повторно прошли 18 PostgreSQL-проверок. Дополнительно прошли 35 проверок остановки, аудио-runtime и operations без сети модели и пользовательских томов.
- На VPS выполнены upgrade и alembic check. STT enabled, protocol confirmed, модель Whisper и лимиты 100/20 проверены в worker. API health вернул 200, monitor ok=true, alerts пуст. Регистрация бессрочная.
- Из контейнера в Хельсинки прошли VPN health, 401 без секрета и с неверным секретом, 422 с правильным секретом и некорректным телом. HTTPS веб и health дали 200, админка без сессии 401, публичные внутренние маршруты 404. Публичный 18000 недоступен.

Работают PostgreSQL, API, scheduler, Caddy, один worker на РФ и один адаптер в Хельсинки. Ключ модели и аудио боту не передавались. Worker сохраняет owner-live и restart=no. По SIGTERM/SIGINT завершает текущую попытку и больше не берёт задания. Резервирование даёт 180 секунд на завершение вместо 30.

## Копия и восстановление

Первая копия сохранилась, но автозапуск служб не прошёл из-за старого migrate-контейнера. Службы возвращены, migrate пересоздан на актуальном образе. Проверочное резервирование завершилось с writers_restarted=true.

Итоговый архив `beresta-20261009T191638-f5e2e56c.tar.age` скачан на ПК. SHA-256 `671ea446451913d47864c70df9a4e599f47ce0c7bd004f79f972723c34a4d8f9` совпал. Копия восстановлена в `beresta-restore-voice-20261009-6da3`, проверен один оригинал аудио, схема e61f893ac204 и счётчик восьми попыток. Приложения и отправитель не запускались. Изолированная БД остановлена, тома сохранены. Ключ age передавался через SSH stdin и на VPS не сохранялся.

## Первый пользовательский прогон

Владелец отложил живую приёмку. Когда будет готов, отправить свою короткую новую голосовую запись в `@beresta_ru_bot`, дождаться текста и открыть ту же заметку в вебе. Сравнить расшифровку с голосом и оценить структуру. Голосовая ИИ-запись занимает два слота, STT и LLM. Пределы действуют для всей истории базы без ежедневного сброса.

Последняя отдельная текстовая попытка отклонена с кодом ungrounded_quote. Цитата модели не совпала с исходником. Исходник сохранён, проверка цитат не ослаблялась, автоматического повтора нет. Полный живой сценарий от голоса до текста в Telegram ещё не подтверждён, он проверен на mock.
