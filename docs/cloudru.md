# Подключение Cloud.ru владельцем приложения

Адаптер реализован для Foundation Models Chat Completions. Проверки выполнены только с вымышленным ключом и подменой HTTP-транспорта. Реальная модель не запускалась; её доступность, качество структурирования и поддержка выбранных параметров ещё не проверены.

Публичная документация: [быстрый старт](https://cloud.ru/docs/foundation-models/ug/topics/quickstart), [аутентификация](https://cloud.ru/docs/foundation-models/ug/topics/api-ref__authentication), [каталог моделей](https://cloud.ru/docs/foundation-models/ug/topics/overview__available__models).

## Что нужно для пользовательского запуска

Провайдер Cloud.ru подтверждён пользователем. Точный ID модели пока неизвестен. Владелец выбирает доступную текстовую модель в своём кабинете или уточняет ID у выдавших ключ организаторов. Пример из документации не доказывает доступность модели конкретному ключу. Агент не проверяет ключ и не запрашивает список моделей.

Для локальной проверки владельцем предусмотрен `start-cloudru.cmd`. Он скрыто запрашивает ключ, предлагает документированную модель `ai-sage/GigaChat3-10B-A1.8B`, устанавливает общий лимит и использует отдельную базу `data/cloudru.db`. Секрет не сохраняется на диск и удаляется из окружения PowerShell после остановки. Как и любой секрет в переменной окружения процесса, во время работы он доступен самому процессу и локальным инструментам с достаточными правами; для сервера нужен штатный secret manager платформы.

Сервер и worker получают следующие настройки через окружение процесса. `.env.example` — справочник, а не автоматически загружаемый конфиг Python.

| Переменная | Значение |
| --- | --- |
| `NOTES_PROVIDER` | `cloudru` |
| `NOTES_ALLOW_LIVE_REQUESTS` | `true`; отдельное явное включение |
| `NOTES_CLOUDRU_MODEL` | Точный ID модели, доступной вашей команде |
| `NOTES_CLOUDRU_API_KEY` | Реальный секрет; нужен только процессу worker при отдельном запуске |
| `NOTES_LIVE_CALL_LIMIT` | Положительный общий предел обращений за всё время работы этой БД |
| `NOTES_LIVE_USER_CALL_LIMIT` | Положительный предел обращений одного пользователя за всё время |

До включения live подготовить HTTPS, закрытую регистрацию после создания аккаунтов пилота, безопасное хранение секрета на сервере, резервное копирование БД и параметры `NOTES_PUBLIC_ORIGIN` / `NOTES_SECURE_COOKIES=true`. Текущий launcher и Compose предназначены для локального mock-демо и принудительно выключают реальные запросы. Не запускать live-окружение агентом.

Адаптер делает один POST на `https://foundation-models.api.cloud.ru/v1/chat/completions` с Bearer-аутентификацией и `response_format={"type":"json_object"}`, без автоматических повторов и переходов по redirect. Ответ ограничен `max_tokens=4000`, вход — 12000 символов. Ограничения числа запросов не являются точным денежным бюджетом: цена зависит от модели и фактического количества токенов.

Слот запроса резервируется в БД до отправки и не возвращается после ошибки: неизвестно, успел ли провайдер обработать запрос. Ошибки 401/403, 429, тайм-аут, неправильный JSON или недостоверная опорная цитата переводят задание в `failed`. Исходная запись остаётся доступной через список заданий. Автоматических повторных платных попыток нет.

Повтор HTTP-запроса с тем же `Idempotency-Key` возвращает прежнее задание. Новый ключ означает новую запись и потенциально новый расход. Для неясного результата сначала проверить существующее задание.

Режим записывается в задание при приёме. Mock-worker не забирает задания Cloud.ru и наоборот. После переключения режима не смешивать демонстрационные данные с данными пилота; использовать отдельные базы. Не менять режим при незавершённых заданиях.

## Проверка качества командой

Начать с короткого текста из кнопки «Попробовать пример», затем проверить собственные записи. Оценить: сохранён ли смысл и неопределённость, не появились ли выдуманные факты, полезна ли разметка, основаны ли выводы на исходнике. Проверка цитаты в коде не доказывает правильность рассуждения модели.

Реальное распознавание речи в эту версию не входит. Текстовый API и ключ доступа к нему не гарантируют доступ к Audio-to-Text; это отдельная интеграция.
