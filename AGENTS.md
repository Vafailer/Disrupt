# Правила работы с проектом

## Ключ Cloud.ru

Пользователь запретил агентам тратить выданный команде API-токен. Запрет касается любых запросов к сервису, в том числе генерации, распознавания, списка моделей, проверки доступа и баланса. Ключ в окружении не меняет это правило. Не ищите его значение, не копируйте в команды, чат, логи, фикстуры или Git.

Для разработки и CI используйте только предсказуемые `mock`-провайдеры. Переключать тесты на реальный сервис или делать автоматический переход из `mock` в `live` нельзя. Публичную документацию можно читать без ключа. Адаптеры проверяйте с подменённым HTTP-транспортом и прямо указывайте, что живой сервис не проверен. Реальные пользовательские запросы возможны только в отдельно настроенном окружении владельца; агент не отправляет их ради проверки.

Не публикуйте исходные мемо, материалы конкурса, записи и аудио пользователей. В Git должны быть код и нужная команде техническая документация.

## Разработка

- При совместной работе читайте `docs/team-workflow.md`. Перед изменением общего API читайте `docs/integration-v1.md` и `docs/integration-adapter-check.md`. Соблюдайте границы файлов, согласовывайте контракт и не объединяйте ветки без поручения пользователя.

- Сверяйтесь с `docs/backend-plan.md` и README. Отделяйте планы от того, что уже работает и проверено.
- Проверяйте владельца при каждом обращении к заметкам, заданиям и контексту ИИ.
- Не давайте модели прямого доступа к базе, SQL, файлам и произвольным HTTP-запросам. Все действия проходят через функции приложения с проверкой аргументов и прав.
- Сохраняйте исходный текст до обработки. Правки готовой заметки требуют подтверждения пользователя и проверки версии.
- Делайте небольшие коммиты по смыслу. Опубликованную историю без отдельной просьбы не переписывайте.

## Текст для чтения

Пишите в стиле владельца проекта, коротко и прямо. Не используйте длинные тире, шаблонные обороты и канцелярские фразы. Избегайте предложений с двоеточием там, где можно написать обычную фразу. Названия полей, команды и технический смысл сохраняйте.
