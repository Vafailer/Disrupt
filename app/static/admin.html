Вход в админку

Нужны логин администратора, пароль и шестизначный код из приложения-аутентификатора. Обычный аккаунт beresta здесь не подходит.

Как используют beresta

Пользователи, целевые действия и расходы. Дни считаются по Москве. Тестовые аккаунты и фоновая активность исключаются сервером.

Источник — код привлечения; all означает все источники. CSV содержит агрегаты, без личных записей и списка операций.

Удержание

D1 и D7 учитывают только созревшие когорты. Если окно наблюдения ещё не завершилось, результат не считается нулём.

Расходы и токены

Неизвестные расходы показаны отдельно от известной части. Оценка не заменяет измеренную стоимость. LLM cost/DAU использует сумму дневных DAU за период.

Обработка и напоминания

Неизвестный результат отправки не означает доставку. Такая попытка не повторяется автоматически.

Модельные операции

Только технические идентификаторы, без текстов, аудио, имён и контактов. На странице до 50 операций; расходы выше относятся ко всему выбранному периоду.

Обращения пользователей

Ошибки, предложения и вопросы. Содержимое видно только администраторам.

Архив метрик для организаторов

ZIP с таблицами по дням, пользователям, событиям, вызовам ИИ и ошибкам. Внутри README с определениями. Имена, тексты записей и контакты в архив не попадают, пользователи заменены псевдонимами. Тестовые аккаунты исключены. Период не длиннее 92 дней, дни по Москве.
